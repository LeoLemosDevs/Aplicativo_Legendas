## 📋 Próximas Ideias & Roadmap Futuro

### 1. 🎙️ Sincronização Automática com IA (Speech-to-Text / Whisper)
- **Descrição:** Reconhecimento de voz automático no navegador via WebGPU / WebAssembly (Whisper) para alinhar letras de música automaticamente sem precisar bater na tecla espaço.

### 2. 🔤 Upload de Fontes Customizadas Locais (.ttf / .otf / .woff2)
- **Descrição:** Permitir ao usuário carregar arquivos de fontes tipográficas locais do computador para além das famílias do Google Fonts.

### 3. 🎨 Biblioteca de Animações e Stickers Lottie / WebP
- **Descrição:** Catálogo de stickers animados pré-carregados (estrelas, notas musicais, corações, raios neon) prontos para inserir no vídeo.

### 4. 📱 Presets Rápidos de Formato para Mídias Sociais
- **Descrição:** Botões de 1 clique com cortes automáticos de duração (15s, 30s, 60s) para Instagram Stories, TikTok e YouTube Shorts.
